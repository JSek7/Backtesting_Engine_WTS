# Demonstration tape only

This is an 80-tick, three-asset hand-constructed example for installation and
regression testing. It is NOT an export of the competition simulator and is not
representative of competition conditions. Its repeated pattern must not be used
as evidence that a strategy is profitable.

The values in market_info.json are demo trading rules, not tournament rules.
Obtain a public training pack from the organisers and use --scenario to test it.
This directory contains no future-value labels, market model or generation code.
